# aiwangym.github.io

Starter personal academic homepage for GitHub Pages.

## URL

After deployment, the website should be available at:

https://aiwangym.github.io

## How to use

1. Make sure your GitHub username is `aiwangym`.
2. Create a public GitHub repository named `aiwangym.github.io`.
3. Upload `index.html`, `style.css`, and the `assets/` folder to the repository.
4. Go to repository Settings -> Pages.
5. Set Build and deployment source to `Deploy from a branch`.
6. Select branch `main` and folder `/root`.
7. Visit `https://aiwangym.github.io`.
